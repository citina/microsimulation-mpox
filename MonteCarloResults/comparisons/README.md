# Monte Carlo Scenario Comparisons

Bootstrap summaries comparing pairs of scenarios live here. Files are generated by `bootstrap_mpox.m` when `comparison_pairs` is non-empty.

Each CSV contains:
- `Week`: epidemiological week index
- `MeanDiff`: mean difference (scenario A minus scenario B)
- `LowerBound`/`UpperBound`: 95% bootstrap interval

Safe to delete/regenerate as needed.
